# TiendaAccesorios

Este proyecto es una página web desarrollada para el curso de React. -Pre-Entrega-

Es la migración a React de la tienda de accesorios para lectores hecha antes en HTML/CSS/JS puro.

## Descripción

TiendaAccesorios es una tienda online de accesorios para lectores, donde se pueden encontrar productos como marcapáginas, luces de lectura y fundas para libros.

## Tecnologías utilizadas

- React
- React Router DOM - En desarrollo
- Context API
- Vite
- CSS (Flexbox, Grid, Media Queries)

## Funcionalidades

- Navegación con React Router (Inicio, Productos, Detalle de producto, Carrito) - En desarrollo
- Catálogo de productos cargado desde `productos.json` con `fetch` y `useEffect`
- Carrito de compras manejado con Context API (agregar, ver cantidad total, eliminar) - En desarrollo
- Diseño responsivo
- Formulario

## Cómo correr el proyecto

```
npm install
npm run dev
```
